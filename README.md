# Advent of Code Practice

My Python solutions for the [Advent of Code](https://adventofcode.com) coding puzzles. I hand write the code for practice, and only really looked things up if I couldn't find a solution alone. So don't be suprised if some of the solutions are a kind of stupid! I'm intentionally limit testing myself here. 

Probably best to find other code if you want a good represenation of how to do it well.

## Dir Structure

The code is organized by year and day, with the puzzle input included in each day's directory.

```text
.
├── 2024/
│   ├── day1/
│   │   ├── day1.py
│   │   └── somedata.txt
│   └── day2/
└── 2025/
    └── day1/
```


## Solutions

I ran solutions with python3 on a Linux machine, it should be relatively easy to try the solutions out if you want. Go to the directory and run something like:

```bash
cd 2024/day1
python3 day1.py
```
